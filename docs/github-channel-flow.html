🤖 GitHub Channel v1

定时轮询 GitHub Issue → LLM 讨论 → 自动生成 Pull Request

⏱️ Poller

  • 每 5 分钟 调用 GitHub Issues API
  • 获取 updated_since 的 open issue
  • 跳过 PR、bot 评论、已处理的 issue
  • 检测新 comment → 入队 worker
in-flight 跟踪防止重复处理 · 零 comment 重入防护 · 种子标记跳过存量 issue
⤵

📦 Work Queue

📋
缓冲 500 个 WorkItem
2 个 worker goroutine 消费
⤵

⚙️ Worker — processWorkItem

new → discussing → waiting_author
ready_for_pr → implementing → pr_created
skipped (terminal)

💬 讨论 Agent READ ONLY

  • NewAIAgent + 只读工具白名单
  • Issue body + comments 包裹 --- BEGIN UNTRUSTED ---
  • 英文系统提示词：注入防护 + 输出协议
  • 解析回复：[NO_REPLY] → 等待 · [READY_FOR_PR] → 准备实现
  • 通过 GitHub API 发布 comment
ReadFile Grep Glob WebSearch WebFetch
无 Memory · 无 Skill · 无 Bash · 无 WriteFile · 最多 10 轮迭代
⤵

🔧 PR 生成 Agent READ-WRITE

  • PR 门控：author_association + label 白名单
  • git worktree add -b tachi/issue-N-UUID
  • Bash 真白名单：allow + * ask 兜底 (fail-closed)
  • WriteFile 限定 worktree 内 (PathPolicy)
  • git push via extraheader (不落盘) → API 创建 Draft PR
ReadFile WriteFile EditFile Bash Glob Grep
worktree 用完即删 · 分支名含 UUID 防重试冲突 · 最多 50 轮迭代 · 3 次重试上限

🛡️ 安全四层

L1
输入检测
高置信模式 WARN · 低置信 INFO
不修改内容，不暴露规则
L2
系统提示词
UNTRUSTED 标记包裹
禁止泄露/执行/信任
L3
工具隔离
讨论只读 · 实现 worktree
PathPolicy · Bash 白名单
L4
门控+预算
PR 门控 · 迭代上限
超时跳过 · crash 恢复

⚙️ 配置示例

# 认证方式二选一：
token_env: "GITHUB_TOKEN"
# github_app:
# app_id: 123456
# private_key_path: "/path/to/key.pem"
# installation_id: 789012

repos:
  - name: "owner/my-repo"
    local_path: "/home/user/code/my-repo"
    default_branch: "main"

poll_interval: "5m"

behavior:
  pr_as_draft: true
  max_discussion_turns: 10
  max_implementation_turns: 50

security:
  pr_gate:
    allowed_associations: ["OWNER", "MEMBER", "COLLABORATOR"]
  bash_allow:
    - "git *"
    - "rg *"
    - "go *"
🔑 PAT 认证
  • token 或 token_env 直配
  • 简单直接，适合个人试用
  • issue 评论显示为 PAT 持有者
🔐 GitHub App 认证
  • app_id + private_key + installation_id
  • JWT → installation token (1h 过期)
  • 真正的 bot 身份，权限最小化
  • PKCS1 和 PKCS8 密钥均支持
