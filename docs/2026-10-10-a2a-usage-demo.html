    看到的东西它回答什么
    工具结果（带本地 ID d_7f3a）“刚才那件事”是哪一件，下一轮追问直接引用
    系统提醒（PeersReminder / RemoteTasksReminder）有哪些节点可用；这段对话关联过哪些远程任务、有没有等你回答的
    执行记录（侧栏里的只读会话）远端请求在这台机器上具体做了什么
    入口首版行为
    channel / TUI / Desktop 的普通回合配置开启时可用委派与任务查询
    ACP / -p不承载节点，也不隐式获得委派
    cron / 系统回调 / ambient回合级禁用委派（没点名要它干的活）
    subagent / fork / dream / 一次性命令默认不继承委派
    tachi web只读控制台，不承载节点
