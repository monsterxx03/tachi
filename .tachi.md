# Tachi — AI Agent CLI

Terminal-based AI agent (bubbletea TUI) for LLM conversations + tool use.

## Build & Test

```bash
make build          # go build -ldflags="..." -o tachi
make build-linux    # cross-compile for linux/amd64
make test           # go test ./...
go test -v ./agent/tools -run TestEditFile  # single test
```

## Storage (~/.tachi/)

## Architecture

```
main.go → config.Load → AIAgent.Configure() → tui.Run()
                         ├── llm.Provider (OpenAI/Anthropic + title/commit providers)
                         ├── tools.Registry (built-ins alphabetically, MCPs in reg order)
                         ├── mcp.Manager (async init, deferred pool, discovered set)
                         ├── session.Manager (JSONL)
                         ├── systemreminder.Collector (ephemeral <system-reminder> blocks)
                         └── cron.Scheduler (robfig/cron, store-backed)
```

### Agent Loop (`agent/agent_loop.go`)

`RunConversationStream(history, userMsg, systemPrompt) → chan AgentEvent` — main TUI loop.
`RunOneOffStream(...)` — /commit, /init, sub-agents, channels.

`runAgentLoop()` shared by both: `for { consume budget → buildLLMTools → CreateChatStream → consumeStream → handleFinishReason }`
- `stop` → TurnComplete + storeTurnMemory
- `tool_calls` → executeToolCalls + steer check + loop reminders → loop
- `length` → continuation (max 3 retries, context-aware prompt) → loop

Iteration budget: TUI/channel unlimited, `tachi run` capped (default 50).

### TUI (`tui/model.go`)

`stateIdle → stateWaiting → stateStreaming → stateIdle`. States: `AwaitingConfirmation` (EditFile diff), `AskUserQuestion` (form), `SelectingModel`, `SelectingSession`. `Ctrl+O`: thinking view, `Ctrl+S`: copy, `Ctrl+C`: cancel pending steer. `pendingQueue`: input during streaming → `[待发送]` → drained on TurnComplete/steer. Statusbar context fraction = `lastInputTokens / contextWindow`.

### Token Estimation (`agent/token_estimate.go`)

`estimateInputTokens()` — chars/4 heuristic (overestimates). Set via `estimateAndUpdateTokens` → `a.lastInputTokens`. Used by `TokenWarningReminder` (threshold default 80%) + statusbar. Actual API usage replaces estimate.

### Memory (`agent/memory/`, `agent/agent_memory.go`)

Pluggable backends (mem9 default, agentmemory). Scopes: `Start` (new session), `Turn` (after TurnComplete), `Compact` (before compaction), `Session` (end/shutdown). `SkipWrites` for one-off runs. `SkipRecall` for `tachi run`. `exclude_repos` config. `MemoryRecallReminder` injects relevant past memories.

### Skills (`agent/skill/`, `agent/agent_skill.go`)

Skills from `~/.tachi/skills/` + `.tachi/skills/`. `Skill(operation="view")` tool activates. `ReloadSkills()` rescans. `SkillListReminder` shows available.

### Tools (`agent/tools/tool.go`)

Interface: `Name()/Description()/Properties()/Required()/Parallel()/ExecuteContext()`. `ConfirmationTool`: 3-phase (Invoke→Confirm→ExecuteConfirmed). `AskUserQuestionError` → TUI form. Registration: built-ins alphabetically + MCPs in reg order (monotonic for cache).

| Tool | Par | Notes |
|------|-----|-------|
| AskUserQuestion | no | blocks for input |
| Bash | no | bg process support via ProcessManager |
| Cron | no | scheduled jobs CRUD |
| EditFile | no | 3-phase confirm |
| Glob/Grep | yes | rg-based |
| MCPSearchTools | yes | search+load deferred MCP tools |
| MemoryRecall/MemoryRecord | yes/no | semantic search / explicit write |
| ReadFile | yes | |
| SendFile | no | channel-only, deferred delivery |
| Skill | no | CRUD + list |
| SubAgent | yes | max_concurrency=4 semaphore |
| WebFetch/WebSearch | yes | always / Brave/Serper/SerpAPI |
| WriteFile | no | |

### SubAgent (`agent/subagent.go`)

Isolated child agent. Inherits tools minus AskUser/SubAgent/EditFile confirm. Skips memory/session. Recorded to `subagent/<id>.jsonl`. Worktree mode: `git worktree add --detach`, cleanup produces `[WORKTREE_PATCH]` (≤32KB). Falls back to shared dir. `wdctx.Dir(ctx)` for all tool paths.

### MCP (`agent/mcp/`)

Stdio/Streamable HTTP, OAuth2+PKCE+DCR. Tools: `mcp__<server>__<tool>`. Deferred discovery: `DeferredPool` → LLM uses `MCPSearchTools` → `DiscoveredSet`. Async init: `InitMCPAsync` → bg connect, `WaitForMCP` blocks ≤5s. TUI: `/mcp list|toggle|reconnect|auth`. `SetSharedMCP` for channel mode.

### Cron (`cron/` + `agent/tools/cron.go`)

`robfig/cron` + store. Types: `oneshot` (default, auto-delete) / `recurring`. Notify: `always` / `when_relevant`. Max 50 jobs, 3 concurrent, 5m timeout.

### Steer (`agent/agent.go`, `llm/provider.go`)

`llm.RoleSteer` injected at tool-call boundaries (after results, before next API). NOT on length continuation. Anthropic: merged as text block into same user message as tool_result. OpenAI: separate user message.

### Channel (`channel/`)

IM abstraction via registry. Interface: `Run(ctx, handler)`. Per-turn AIAgent instances with shared MCP + process manager + agent cache. SendFile: validates→queues path, channel reads from disk at send time. WeChat: polling-based, enterprise protocol.

### ACP (`agent/acp/`)

Agent Communication Protocol (JSON-RPC 2.0 over stdio). `tachi acp`. Per-session isolation, streaming, external permission handler.

### Process Manager (`agent/tools/process_manager.go`)

Background bash (Bash `background=true`). Process group isolation (SIGTERM→5s→SIGKILL). 64KB ringbuf per process. `KillAll()` on close, `DrainCompleted()` for loop reminders.

### Session Compaction (`agent/compact.go`)

LLM summarizes → new session with `compacted_parent_id` link. `FinalizeCompact()` creates child session. `BuildCompactInstruction()` yields prompt. `StoreCompactMemory()` before compaction.

### Config (`config/config.go`)

YAML. Named providers (type/model/key/base_url/context_window). Web search: brave/serper/serpapi. Memory: mem9/agentmemory. Channel: channels map. `language` sets reply language. Reminder thresholds in `system_reminder.*`. CLI flags override.

### @-File References (`tui/at_file.go`)

`@` → fuzzy completion via `PathTrie` (rg --files, 30s cache). Text files inlined with `--- BEGIN UNTRUSTED FILE CONTENT ---`. Binaries → `[@file: path]` for LLM tool access. TUI shows unexpanded `@path`.

## CLI

| Command | Purpose |
|---------|---------|
| `tachi` | Interactive TUI |
| `tachi --resume` | Resume latest session |
| `tachi run --prompt "..."` | Non-interactive (stdin also accepted) |
| `tachi run --prompt "..." --json` | Structured JSON output |
| `tachi run --prompt "..." --timeout 5m` | With timeout |
| `tachi init` | Create config |
| `tachi channel` | Start IM channels |
| `tachi acp` | ACP JSON-RPC agent |
| `tachi transcript list\|show` | Session browser + HTML report |
