# Tachi - AI Agent CLI

Terminal-based AI agent with TUI for LLM conversations + tool use.

## Build

```bash
make build              # go build -ldflags="-X main.Version=... -X .../llm.Version=..." -o tachi .
make build-linux        # GOOS=linux GOARCH=amd64 cross-compile
make test               # go test ./...
go test -v ./tools -run TestEditFile  # single test
```

## Storage (~/.tachi/)

| Path | Purpose |
|------|---------|
| `config.yaml` | Provider configs, subagent settings, MCP servers |
| `input_history` | Persistent input history |
| `session/<id>/meta.json` + `messages.jsonl` | Session metadata + flat message log |
| `session/<id>/subagent/<shortID>.jsonl` | Per-subagent execution record |
| `mcp_tokens/<name>.json` | OAuth tokens per MCP server |
| `logs/debug.log` | `debuglog.Log()` output |

## Architecture

```
main.go → config load → AIAgent.Configure() → TUI (bubbletea)
                         ├── llm.Provider (OpenAI/Anthropic)
                         ├── tools.Registry
                         ├── mcp.Manager (optional)
                         ├── session.Manager
                         └── systemreminder.Collector
```

### Agent Loop (`agent/agent.go`)

- `RunConversationStream(ctx, history, userMsg, systemPrompt, opts) → chan AgentEvent` — main TUI loop
- `RunOneOffStream(...)` — used by `/commit`, `/init`, sub-agents, channels
- `handleFinishReason`: `stop`→done, `tool_calls`→execute→loop, `length`→auto-continue (max 3 retries)
- Iteration budget enforced; TUI/channel modes unlimited, `tachi run` capped at config value (default 50)
- `steerRespCh`: between tool execution and next API call, checks for queued user input and injects mid-turn

### TUI State Machine (`tui/model.go`)

`stateIdle → stateWaiting → stateStreaming → stateIdle`
- `stateAwaitingConfirmation`: EditFile diff approval
- `stateAskUserQuestion`: AskUser form
- `stateSelectingModel`, `stateSelectingSession`: `/model`, `/sessions`
- `Ctrl+O`: fullscreen thinking view; `Ctrl+S`: copy mode
- `pendingQueue`: input enabled during streaming, messages queued as `[待发送]` placeholders, auto-drained on TurnComplete or via Steer

### Tools (`agent/tools/tool.go`)

Interface: `Name() / Description() / Properties() / Required() / Parallel() / ExecuteContext(ctx, args)`
- `ConfirmationTool` (EditFile): `NeedsConfirmation()` + `GetDiff()` — three-phase: Invoke → Confirm → ExecuteConfirmed
- `AskUserQuestionError`: special error triggers TUI form
- `ToolResult.SubagentID`: set by SubAgent tool for linking to `subagent/<id>.jsonl`

Tool constants: `ToolNameAskUser, ToolNameSubAgent, ToolNameBash, ToolNameRead, ToolNameWrite, ToolNameEdit, ToolNameGlob, ToolNameGrep, ToolNameWebSearch, ToolNameWebFetch`

### SubAgent (`agent/subagent.go`, `agent/tools/subagent.go`)

LLM-delegated isolated child agents. `Parallel()=true`, gated by `max_concurrency` semaphore (default 4).

Config (`subagent.*`): `provider/model` (fallback to main), `max_iterations` (50), `max_concurrency` (4), `max_output_chars` (16384, auto-truncate), `thinking` (false)

Tool params: `prompt`, `allowed_tools` (empty=all except AskUser+SubAgent), `max_iterations`, `worktree_branch`

Child agent: `skipEditConfirm=true`, no AskUser, no session, no reminders, no SubAgent tool (recursion blocked at code+prompt level). Output recorded to `session/<id>/subagent/<shortID>.jsonl` via `SubagentRecorder`.

### SubAgent Worktree (`agent/subagent_worktree.go`, `agent/wdctx/workingdir.go`)

When `subagent.worktree: true`: each sub-agent gets `git worktree add --detach` checkout.
- `wdctx.WithDir(ctx, path)` / `wdctx.Dir(ctx)`: context-based working dir, all tools resolve relative paths through it. Falls back to global `getWorkingDir()`.
- On cleanup: `git add -A && git diff --cached` → patch wrapped in `[WORKTREE_PATCH]...[/WORKTREE_PATCH]`, appended to output. >32KB truncated.
- `worktree_branch` param overrides config default. Auto `git fetch origin <branch>` if missing.
- Degrades to shared dir if not a git repo or `git worktree add` fails.

### Steer Mechanism (`agent/agent.go`, `llm/provider.go`)

Internal `llm.RoleSteer` injected at tool-call boundaries (after `handleFinishReason` for `tool_calls`/`tool_use`, before next API call). NOT on `length`/`max_tokens` continuation.

Per-provider encoding:
- **Anthropic**: merged as `text` content block into same `user` message as `tool_result` blocks (avoids alternating role violation)
- **OpenAI**: separate `role: "user"` message

Session records as `MessageTypeUser`.

### MCP (`agent/mcp/`)

`mcp.Manager` handles tool servers over stdio or Streamable HTTP. OAuth2 with PKCE, DCR when no `client_id`, token persistence. Tools wrapped as `MCPTool` named `mcp__<server>__<tool>`.

Config: `mcp_servers` in config.yaml. TUI: `/mcp list|toggle|reconnect|auth`.

### Channel (`channel/`)

IM platforms (WeChat, Slack, Telegram) → `Channel` interface: `Run(ctx, handler)`. Each `ThreadID` maps to persistent session. `skipEditConfirm=true`, no AskUser. `/new` starts fresh session, `/mcp` lists servers.

### System Reminders (`agent/systemreminder/`)

`<system-reminder>` blocks injected at top of user messages (not static system prompt). Includes: DateReminder, ProjectContextReminder (.tachi.md), GitReminder (branch+status), IterationWarningReminder, TokenWarningReminder. Aggregated via `Collector.Collect()`.

### @-File References (`tui/at_file.go`)

`@` triggers fuzzy completion via cached `PathTrie` (rg --files, 30s cache). `ExpandAtReferences()` annotates `@path` as `[@file: path]` / `[@dir: path]` without inlining content; LLM uses ReadFile/Bash/Glob tools to read when needed. TUI shows unexpanded `@path`.

### Session (`session/`)

Flat `messages.jsonl` per session. `agent/session_convert.go` → `llm.Message[]` for resume.
- Anthropic resume: thinking blocks → `ThinkingBlocks` on assistant message
- OpenAI resume: thinking prepended to assistant `Content`

`Manager.FindByThreadID()` for channel session lookup.

### Config (`config/config.go`)

YAML at `~/.tachi/config.yaml`. Named providers with type/model/key/base_url/context_window. Env vars: `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`. CLI flags override. `language` field sets reply language. Web search: Brave/Serper/SerpAPI.

## CLI

```bash
tachi                    # interactive TUI
tachi --resume           # resume latest session
tachi run --prompt "..." # non-interactive single-turn
tachi init               # create config
tachi transcript list    # list sessions with execution data
tachi transcript show --session <id>  # HTML report (opens browser)
tachi transcript show --latest
```

## Slash Commands

`/new`, `/model`, `/commit` (auto commit msg + Co-authored-by), `/init` (generate .tachi.md), `/mcp list|toggle|reconnect|auth`, `/sessions`, `/quit`

| Package | Purpose |
|---------|---------|
| `agent/` | AIAgent, event loop, subagent executor, worktree manager |

| `agent/systemreminder/` | Dynamic reminder injection |
| `agent/transcript/` | Execution recording, HTML report generation |
| `agent/wdctx/` | Context-based working dir for worktree isolation |
| `channel/` | IM platform abstraction |
| `config/` | YAML config, provider resolution, SubagentConfig |
| `llm/` | Provider interface, OpenAI+Anthropic, model info, RoleSteer |
| `pkg/debuglog/` | File-based debug logging |
| `pkg/pathtrie/` | Path trie for @-file completion |
| `session/` | Session store, JSONL persistence, SubagentID |
| `tui/` | Bubble Tea UI: model, views, input, commands, pending/steer |
