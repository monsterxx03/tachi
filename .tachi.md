# Tachi — AI Agent CLI

Terminal-based AI agent (bubbletea TUI) for LLM conversations + tool use.
Language: **Go 1.26.3** (`go.mod` / `.tool-versions`)

## Build & Test

```bash
make build                 # go build -ldflags="..." -o tachi
make build-linux           # cross-compile linux/amd64
make build-linux-arm64     # cross-compile linux/arm64
make test                  # go test ./...
make test-cover            # coverage per-package, sorted desc
make test-cover-html       # coverage + open browser
go test -v ./agent/tools -run TestEditFile  # single test
```

LDFLAGS injects `Version` into both `main` and `llm` packages:
`-X main.Version=$(git describe --tags --always --dirty) -X github.com/monsterxx03/tachi/llm.Version=...`

Workspace mode (`go.work`): links `tachi-wave` (external channel plugin at
`platgit.mihoyo.com/yejia.xu/tachi-wave`) without pulling it into `go.mod`.
`third_party_channels.go` imports it with a build tag.

## Architecture

```
main.go → config.Load → AIAgent.Configure() → tui.Run()
                         ├── llm.Provider (OpenAI/Anthropic)
                         ├── tools.Registry (built-ins alpha + MCPs in reg order)
                         ├── mcp.Manager (async init, deferred pool, discovered set)
                         ├── session.Manager (JSONL)
                         ├── systemreminder.Collector (ephemeral <system-reminder> blocks)
                         ├── cron.Scheduler (robfig/cron, store-backed)
                         ├── cron.SystemScheduler (programmatic; dream scheduler)
                         ├── lsp.Manager (per-extension LSP server routing)
                         └── dream.Orchestrator (gate/lock/group logic)
```

### Agent Loop (`agent/agent_loop.go`)

`RunConversationStream(history, userMsg, systemPrompt) → chan AgentEvent` — main TUI loop.
`RunOneOffStream(...)` — /commit, /init, sub-agents, channels, dreams.

`runAgentLoop()` shared: `for { consume budget → buildLLMTools → CreateChatStream → consumeStream → handleFinishReason }`
- `stop` → TurnComplete + storeTurnMemory
- `tool_calls` → executeToolCalls + steer check + loop reminders → loop
- `length` → continuation (max 3 retries, context-aware prompt) → loop

Iteration budget: TUI/channel unlimited, `tachi -p` / pipe capped (default 50).
Slash command metadata in `agent/commands/` (shared registry for TUI, channel, ACP).

### TUI (`tui/model.go`)

`stateIdle → stateWaiting → stateStreaming → stateIdle`. Modal states: `AwaitingConfirmation` (EditFile diff), `AskUserQuestion` (form), `SelectingModel`, `SelectingSession`. `Ctrl+O`: thinking view, `Ctrl+S`: copy, `Ctrl+C`: cancel steer. `pendingQueue`: input during streaming → `[待发送]` → drained on TurnComplete/steer. Statusbar: `lastInputTokens / contextWindow`.

### Edit Mode: HashLine (`agent/tools/hashline/`)

Two modes via `config.edit.mode`:
- **replace** (default): exact string replacement (3-phase confirmation)
- **hashline**: `¶PATH#TAG` header + operations (`replace N..M`, `insert_after N`, `delete N..M`, etc.) with SHA-256 4-char snapshot tags. `ReadFile` records tags, `EditFile` verifies. 2-phase prepare/commit, fuzzy context line matching (`fuzzy_threshold`, default 0.95). No `-` rows in body — range already names lines.

### LSP Integration (`agent/lsp/`)

Per-extension LSP server routing. Configured via `config.lsp.servers[]` (command, args, extensions, languages, workspace_folder). Lazy startup on first access, max 3 restarts, 10MB file cap, 4 concurrent ops per server. `LSP` tool: goToDefinition, findReferences, hover, documentSymbol, workspaceSymbol, goToImplementation, prepareCallHierarchy, incomingCalls, outgoingCalls.

### Tool Registry (`agent/tools/tool.go`, `agent/agent.go:RegisterTools()`)

Interface: `Name()/Description()/Properties()/Required()/Parallel()/ExecuteContext()`. `ConfirmationTool`: 3-phase (Invoke→Confirm→ExecuteConfirmed). `AskUserQuestionError` → TUI form. Built-ins registered alpha, MCPs appended (monotonic cache key). Edit mode config wires `hashline.NewSnapshotStore()` → shared between ReadFile (records) + EditFile (verifies).

| Tool | Par | Notes |
|------|-----|-------|
| AskUserQuestion | no | blocks for TUI form |
| Bash | no | bg via ProcessManager |
| Cron | no | scheduled jobs CRUD |
| EditFile | no | hashline or replace mode |
| Glob/Grep | yes | rg-based |
| LSP | no | code intelligence |
| MCPSearchTools | yes | search+load deferred MCP |
| MemoryRecall/MemoryRecord | yes/no | semantic search / explicit write |
| ReadFile | yes | hashline tag recording |
| SendFile | no | channel-only, deferred |
| Skill | no | CRUD + list |
| SubAgent | yes | max_concurrency=4 semaphore |
| WebFetch/WebSearch | yes | Brave/Serper/SerpAPI |
| WriteFile | no | |

### SubAgent (`agent/subagent/`)

Isolated child agent. Inherits tools minus AskUser/SubAgent/EditFile confirm. Skips memory/session. Recorded to `subagent/<id>.jsonl`. Worktree mode: `git worktree add --detach`, cleanup produces `[WORKTREE_PATCH]` (≤32KB). Falls back to shared dir. `wdctx.Dir(ctx)` for all tool paths — context-based working directory isolation without global state.

### MCP (`agent/mcp/`)

Stdio/Streamable HTTP, OAuth2+PKCE+DCR. Tools: `mcp__<server>__<tool>`. Deferred: `DeferredPool` → LLM uses `MCPSearchTools` → `DiscoveredSet`. Async init: `InitMCPAsync` → bg connect, `WaitForMCP` blocks ≤5s. TUI: `/mcp list|toggle|reconnect|auth`. `SetSharedMCP` for channel mode.

### Channel (`channel/`, `pkg/channel/`)

IM abstraction: `channel.Register(name, factory)` in `init()`. Three types:

| Channel | Transport | Notes |
|---------|-----------|-------|
| `weixin` | HTTP polling | Enterprise WeChat, crypto, media upload |
| `chrome` | Chrome Native Messaging | stdin/stdout, 4-byte LE length-prefixed JSON |
| `tachi-wave` | External (go.work) | `third_party_channels.go` build-tag import |

`channel/manager/` owns per-turn AIAgent instances with shared MCP + process manager + agent cache.
SendFile validates→queues path; channel reads from disk at send time.
Chrome channel auto-detects `chrome-extension://` prefix in argv → redirects to channel mode.

### Chrome Extension (`chrome-extension/`)

Browser companion (JS/HTML). Sidepanel + popup UI. Actions: search, explain,
remember, recall, ask_tachi. Communicates via Chrome Native Messaging to the
`chrome` channel. Separate build (`chrome-extension/Makefile`), outputs to
`chrome-extension/dist/`.

### Dream — AutoDream (`dream/` + `channel/manager/dream.go`)

Background memory consolidation (channel mode). `cron.SystemScheduler` triggers per config schedule (default daily 3 AM). Pipeline: sessions grouped by git root (project) or global → gates (min_interval, active sessions, lock) → sub-agent (sandboxed tools, writes restricted to `.tachi/memory/`). LLM runs Orient→Gather→Consolidate→Prune, writes topic files. `SkipDream` per-session flag. Lock: `dream.lock` with PID + timestamp staleness check.

### Session Compaction (`agent/compact.go`)

`/compact` command + auto-compact (triggered at `lastInputTokens/contextWindow >= threshold`, default 80%). LLM summarizes → new session with `compacted_parent_id` link. `StoreCompactMemory()` before compaction. Config: `compact.timeout` (5m), `compact.max_tokens` (4096), `compact.auto` (true).

### Memory (`agent/memory/`, `agent/agent_memory.go`)

Pluggable backends: **mem9** (default, mem9.ai API) or **agentmemory**. Scopes: `Start`/`Turn`/`Compact`/`Session`. `SkipWrites` for one-off runs. `SkipRecall` for `tachi -p` / pipe. `MemoryRecallReminder` injects memories. Keyword extraction (`agent/extractor.go`): LLM extracts 3-5 bilingual (CN+EN) keywords from query for text-based recall precision.

Skills: `.tachi/skills/` → `.claude/skills/` → `.cursor/skills/` → `~/.tachi/skills/`. `Skill(operation="view")` activates, `SkillListReminder` shows available.

### Steer & Process Manager (`agent/agent.go`, `agent/tools/process_manager.go`)

`llm.RoleSteer` injected at tool-call boundaries (after results, before next API call). NOT on length continuation. Anthropic: merged into same user message as tool_result. OpenAI: separate user message. Process Manager: bg bash (SIGTERM→5s→SIGKILL), 64KB ringbuf per process, `KillAll()` on close.

### ACP — Agent Client Protocol (`agent/acp/`)

JSON-RPC 2.0 over stdio (`tachi acp`). Bridges `coder/acp-go-sdk` to `AIAgent`. Per-session isolation, streaming, configurable MCP connection policy. Slash commands stream results as `SessionUpdate`. Optional external permission handler.

### Cron (`cron/` + `agent/tools/cron.go`)

Two schedulers:
- **User** (`cron.Scheduler`): store-backed, max 50 jobs, 3 concurrent, 5m timeout. Types: `oneshot` (auto-delete) / `recurring`. Notify: `always` / `when_relevant`. Managed via CronTool.
- **System** (`cron.SystemScheduler`): programmatic, no store, invisible to LLM. Used for AutoDream.

### Config (`config/config.go`)

YAML. Named providers (type/model/key/base_url/context_window). Web search: brave/serper/serpapi. Memory: mem9/agentmemory. Channel: channels map. `language` sets reply language. Reminder thresholds in `system_reminder.*`. CLI flags override.

### @-File References (`tui/at_file.go`)

`@` → fuzzy completion via `PathTrie` (rg --files, 30s cache). Text files inlined with `--- BEGIN UNTRUSTED FILE CONTENT ---`. Binaries → `[@file: path]` for LLM access. TUI shows unexpanded `@path`.

## CLI

| Command | Purpose |
|---------|---------|
| `tachi` | Interactive TUI |
| `tachi --resume` | Resume latest session |
| `tachi -p "..." [--output-format json] [--timeout 5m]` | Non-interactive (stdin also accepted; pipe without `-p` also works) |

| `tachi chrome install\|uninstall` | Chrome Native Messaging host manifest |
