# Tachi — AI Agent CLI

Terminal-based AI agent (bubbletea TUI) for LLM conversations + tool use.
Language: **Go 1.26.3** (`go.mod` / `.tool-versions`). Runtime dep: **ripgrep (`rg`)** — Glob/Grep/@-file shell out to it.

## Build & Test

```bash
make build                 # go build -ldflags="..." -o tachi
make build-linux{,-arm64}  # cross-compile linux/amd64, linux/arm64
make test                  # go test ./...
make test-cover{,-html}    # coverage per-package sorted desc / + open browser
make lint                  # golangci-lint run ./...   (lint-fix: go fix + --fix)
go test -v ./agent/tools -run TestEditFile  # single test
```

`.golangci.yml` (v2): govet, staticcheck, errcheck, ineffassign, unused. errcheck excluded for `_test.go`, `defer Close/Remove`, `fmt.Fprint*`, `.Encode(`, `os.Remove/Rename/MkdirAll`, `Set(Read|Write)Deadline`.
LDFLAGS injects `Version` into `main` and `llm`: `-X main.Version=$(git describe --tags --always --dirty) -X github.com/monsterxx03/tachi/llm.Version=...`

## Architecture

```
main.go → config.Load → AIAgent.Configure() → tui.Run()
                         ├── llm.Provider (OpenAI/Anthropic)
                         ├── tools.Registry (built-ins + MCPs appended)
                         ├── mcp.Manager (async init, deferred pool, discovered set)
                         ├── session.Manager (JSONL, max 100 sessions)
                         ├── systemreminder.Collector + cron.Scheduler/SystemScheduler (dream)
                         ├── lsp.Manager (per-extension routing, lazy start)
                         ├── permission.Policy (Bash allow/ask/deny glob rules)
                         └── dream.Orchestrator (gate/lock/group logic)
```

### Agent Loop (`agent/agent_loop.go`)

`RunConversationStream(history, userMsg, systemPrompt) → chan AgentEvent` — main TUI loop. `RunOneOffStream(...)` — /commit, /init, sub-agents, channels, dreams.
Shared `runAgentLoop()`: `for { budget → buildLLMTools → CreateChatStream → consumeStream → handleFinishReason }` — `stop` → TurnComplete + storeTurnMemory; `tool_calls` → executeToolCalls + steer check + loop reminders → loop; `length` → continuation (max 3 retries) → loop.

Iteration budget: TUI/channel unlimited; `tachi -p` / pipe capped (default 50). Slash command metadata in `agent/commands/` — shared `Def` registry (Name, Description, Modes: TUI|Channel|ACP).

### Session Modes (`agent/modes.go`)

`auto` (full tools) / `chat` (read-only) / `plan` (read-only + `BuildPlanModePrompt()`). Destructive tools (`IsDestructive()`) hidden in chat/plan. Plan mode: LLM explores read-only; `SavePlan` writes structured plan to `.tachi/plans/` (fallback `~/.tachi/plans/`); tool registered only for frontends with plan-card UI (ACP).

### Permission (`agent/permission/`)

Bash guardrail (not a sandbox): glob rules → allow/ask/deny. Sources: global `config.yaml permissions:` + project `.tachi/permissions.yaml`. `BuiltinDenyRules` honored from global config only. `*` crosses spaces (`git *` matches `git push --force`).

### TUI (`tui/model.go`)

`stateIdle → stateWaiting → stateStreaming → stateIdle`. Modals: `AwaitingConfirmation` (EditFile diff), `AskUserQuestion` (form), `SelectingModel`, `SelectingSession`. `Ctrl+O` thinking view, `Ctrl+S` copy, `Ctrl+C` cancel steer. `pendingQueue`: input during streaming → `[待发送]` → drained on TurnComplete/steer. Statusbar: `lastInputTokens / contextWindow`.

### Edit Mode: HashLine (`agent/tools/hashline/`)

Via `config.edit.mode`: **replace** (default) — exact string replacement, 3-phase confirmation. **hashline** — `¶PATH#TAG` header + ops (`replace N..M`, `insert_after N`, `delete N..M`) with SHA-256 4-char snapshot tags; `ReadFile` records tags, `EditFile` verifies; 2-phase prepare/commit, fuzzy context matching (`fuzzy_threshold`, default 0.95).

### LSP Integration (`agent/lsp/`)

Per-extension server routing (`extIdx map[string]*LSPServer`), configured via `config.lsp.servers[]`. Lazy start, max 3 restarts, 10MB file cap, 4 concurrent ops/server. `LSP` tool: goToDefinition, findReferences, hover, documentSymbol, workspaceSymbol, goToImplementation, callHierarchy. `LSPDiagnostics`: per-file or workspace-wide.

### Tool Registry (`agent/tools/tool.go`, `agent/agent.go:RegisterTools()`)

Interface: `Name/Description/Properties/Required/Parallel/IsDestructive/ExecuteContext`. `ConfirmationTool`: 3-phase (Invoke→Confirm→ExecuteConfirmed). `AskUserQuestionError` → TUI form. Built-ins alpha, MCPs appended (monotonic cache key). PathPolicy via context (`WithPathPolicy`) restricts WriteFile to allowed dirs (sub-agents, dreams). `--allowed-tools`/`--disallowed-tools` filter the registry.

| Tool                      | Par    | Notes                                                                |
| ------------------------- | ------ | -------------------------------------------------------------------- |
| AskUserQuestion           | no     | blocks for TUI form                                                  |
| Bash                      | no     | bg via ProcessManager; permission.Policy gate                        |
| Cron / Skill              | no     | scheduled jobs CRUD / skill CRUD + list                              |
| EditFile                  | no     | hashline or replace mode                                             |
| Glob/Grep                 | yes    | rg-based; Grep plain-text output, `fixed_string` literal mode        |
| LSP / LSPDiagnostics      | no     | code intelligence / diagnostics                                      |
| MCPSearchTools            | yes    | search+load deferred MCP                                             |
| MemoryRecall/MemoryRecord | yes/no | semantic search / explicit write                                     |
| ReadFile                  | yes    | hashline tag recording; per-instance file cache                      |
| SavePlan                  | no     | ACP-only; plan doc → `.tachi/plans/`                                 |
| SendFile                  | no     | channel-only, deferred                                               |
| SubAgent                  | yes    | max_concurrency=4 semaphore                                          |
| WebFetch                  | yes    | no key; oversized results → `~/.tachi/tool_results/` (cap 50K chars) |
| WebSearch                 | yes    | Brave/Serper/SerpAPI; registered only if key set                     |
| WriteFile                 | no     | PathPolicy-gated                                                     |

### SubAgent (`agent/subagent/`) & Fork (`agent/agent_fork.go`)

SubAgent: isolated child; inherits tools minus AskUser/SubAgent/EditFile-confirm; skips memory/session; recorded to `subagent/<id>.jsonl`. Worktree mode: `git worktree add --detach`, cleanup emits `[WORKTREE_PATCH]` (≤32KB); falls back to shared dir. `wdctx.Dir(ctx)` for all tool paths — context-based working-dir isolation, no global state.
Fork: `ForkConfig` creates child from parent; `forkTool()` shares tools by pointer except fresh `ReadTool` (keeps parent file-cache clean). Powers `/review` and deepresearch.

### Deep Research (`agent/deepresearch/`)

`/research <topic> [--depth 2] [--breadth 3]`. Per level: LLM generates `breadth` queries → parallel SubAgents search + extract learnings → recurse `depth-1, breadth/2` if new learnings → final report.

### MCP (`agent/mcp/`)

Stdio/Streamable HTTP, OAuth2+PKCE+DCR. Tools: `mcp__<server>__<tool>`. Deferred: `DeferredPool` → LLM `MCPSearchTools` → `DiscoveredSet`. Async init: `InitMCPAsync` → bg connect, `WaitForMCP` ≤5s. `/mcp list|toggle|reconnect|auth`; toggle purges server tools from registry + deferred pool + discovered set. `SetSharedMCP` for channel mode.

### Channel (`channel/`, `pkg/channel/`)

IM abstraction: `channel.Register(name, factory)` in `init()`.

| Channel   | Transport              | Notes                                                   |
| --------- | ---------------------- | ------------------------------------------------------- |
| `weixin`  | HTTP polling           | Enterprise WeChat, crypto, media upload                 |
| `discord` | Gateway WS (discordgo) | md tables → code blocks; `SuppressEmbeds`; member cache |

`channel/manager/` owns per-turn AIAgent instances w/ shared MCP + process manager + agent cache. SendFile validates→queues path; channel reads from disk at send time. Whisper mode: non-directed group-chat messages guarded (`config.channel.whisper`); `whisperPromptSuffix` lets LLM stay silent.

### Dream — AutoDream (`dream/` + `channel/manager/dream.go`)

Background memory consolidation (channel mode), `cron.SystemScheduler` per config (default daily 3 AM). Pipeline: sessions grouped by git root (project) or global → gates (active sessions, lock) → sandboxed sub-agent (writes restricted to `.tachi/memory/`) runs Orient→Gather→Consolidate→Prune → topic files. `SkipDream` per-session flag. Lock: `dream.lock` w/ PID + staleness check.

### Session Compaction (`agent/agent_compact.go`)

`/compact` + auto-compact at 80% context window. LLM summarizes → new session w/ `compacted_parent_id`; `StoreCompactMemory()` first. Config: `compact.timeout` (5m), `compact.max_tokens` (4096), `compact.auto` (true).

### Memory (`agent/memory/`, `agent/agent_memory.go`)

Backends: **mem9** (default, mem9.ai API) or **agentmemory**. Scopes: `Start`/`Turn`/`Compact`/`Session`. `SkipWrites` for one-off runs; `SkipRecall` for `-p`/pipe. `agent/extractor.go`: LLM extracts 3-5 bilingual (CN+EN) keywords/query → text recall (ripgrep over topic files).
Skills: `.tachi/skills/` → `.claude/skills/` → `.cursor/skills/` → `~/.tachi/skills/`. `Skill(operation="view")` activates; `SkillListReminder` shows available.

### System Reminders (`agent/systemreminder/`)

`Collector` gathers ephemeral `<system-reminder>` blocks injected between turns: date/time, git status, memory recall hits, available skills, LSP diagnostics, deferred MCP hints, token/context warnings, project context (`.tachi.md`). Thresholds in `config.system_reminder.*`.

### Steer & Process Manager (`agent/agent.go`, `agent/tools/process_manager.go`)

`llm.RoleSteer` injected at tool-call boundaries (NOT on length continuation). Anthropic: merged into tool_result user msg; OpenAI: separate user msg. Process Manager: bg bash (SIGTERM→5s→SIGKILL), 64KB ringbuf/process, `KillAll()` on close.

### ACP — Agent Client Protocol (`agent/acp/`)

JSON-RPC 2.0 over stdio (`tachi acp`), bridges `coder/acp-go-sdk` to `AIAgent`. Per-session isolation, streaming, configurable MCP policy. Session modes `auto`/`chat`/`plan` (see Session Modes). Slash commands stream as `SessionUpdate`. Optional external permission handler; `acpFileMode` switches EditFile behavior.

### Cron (`cron/` + `agent/tools/cron.go`)

**User** (`cron.Scheduler`): store-backed, max 50 jobs, 3 concurrent, 5m timeout; `oneshot` (auto-delete) / `recurring`; notify `always` / `when_relevant`; managed via CronTool. **System** (`cron.SystemScheduler`): programmatic, no store, invisible to LLM; used for AutoDream.

### Config (`config/config.go`)

YAML. Named providers (type/model/key/base_url/context_window). Web search brave/serper/serpapi. Memory mem9/agentmemory. `language` sets reply language. Thresholds in `system_reminder.*`. `permissions` Bash rules. `tool_result` WebFetch spill (dir, max chars). CLI flags override.

### Token / Cost Tracking

`agent/tokenbreakdown/` (separate pkg — breaks `agent/` ↔ `agent/commands/` import cycle): chars/4 heuristic categorizes `lastInputTokens` (SystemPrompt, InternalTools, MCPTools, User/AssistantMessages); surfaced via `/usage`. `llm/pricing.go` + `llm/cost.go`: built-in prices (CNY/1M tokens), cumulative session cost, cache-read/creation pricing.

### @-File References (`tui/at_file.go`)

`@` → fuzzy completion via `PathTrie` (rg --files, 30s cache). Text inlined with `--- BEGIN UNTRUSTED FILE CONTENT ---`; binaries → `[@file: path]`. TUI shows unexpanded `@path`.

## CLI

Global flag: `--home <dir>` (state dir, default `~/.tachi`).

| Command                                                                                                        | Purpose                                                           |
| -------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| `tachi` / `tachi --resume` (`-r`)                                                                              | Interactive TUI / resume latest session                           |
| `tachi -e` / `tachi tools [--mcp] [--json]`                                                                    | Open config in editor / list available tools                      |
| `tachi -p "..." [-o text\|json\|json-stream] [-q] [--timeout 5m] [--allowed-tools a,b] [--disallowed-tools c]` | Non-interactive (stdin appended when piped; `-q` auto when piped) |
| `tachi -c [-p "extra"] [-o json]`                                                                              | Git commit (like `/commit`, Bash-only, no thinking)               |
| `tachi init` / `tachi channel` / `tachi acp`                                                                   | Create config / start IM channels / ACP agent                     |
| `tachi transcript list\|show`                                                                                  | Session browser + HTML report (`agent/transcript/render/`)        |

Slash commands (modes in `agent/commands/commands.go`): `/new` `/quit` `/model` `/commit` `/compact` `/init` `/mcp` `/sessions` `/usage` `/review` (agent-fork code review) `/skill` `/transcript` `/dream` `/research <topic>` `/cron` `/cd` `/stop` `/restart` (systemctl, channel-only).
